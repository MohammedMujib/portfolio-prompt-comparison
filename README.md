# مشروع محمد — النسخة المدمجة

تم الحفاظ على الإصدار الأول وصفحة المقارنة، واستبدال الإصدار الثاني بنسخة من mohammed-portfolio-local.zip. الملفان الأصليان لم يتغيرا.

افتح هذا المجلد في Cursor ثم شغّل:

    npm ci
    npm run dev

افتح الرابط الذي يظهر في الطرفية. الصفحة الرئيسية تحتوي ثلاثة أزرار: Version 1، Version 2، المقارنة. الصفحات تحتوي رابط عودة للرئيسية بدل شريط الإصدارات القديم.

الصوت والمقدمة متاحان فقط داخل Version 2 وبعد اختيار المستخدم. مغادرة الإصدار تزيل صفحته بالكامل. المقارنة تعرض نسخة صامتة تتجاوز المقدمة وتوقف حركة الخلفية.

المشروع المحلي المنسوخ في public/local-strong. البرومبت القوي المحدث في 02-STRONG-PROMPT.md معروض تلقائيًا في المقارنة، وهو وصف مجمع للمتطلبات الحالية وليس نص محادثة توليد غير مرفقة. أرشيف الإصدار السابق في archive/previous-version-2.

فحص البناء: npm run build
راجع verification.md للفحوص المنفذة وحدودها. لا نشر تلقائي.
